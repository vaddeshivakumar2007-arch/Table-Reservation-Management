Dining Policy & Logic

Reservation Business Rules

  • 2-Hour Slot Window:

    Each confirmed reservation holds the table for 120 minutes. Conflicting requests within this window are rejected.

  • Capacity Check:

    Guest party size must not exceed the maximum seating capacity configured for the table.

  • Immediate Re-availability:

    Cancelled reservations immediately release the table for other customers.

  • Database Transactions:

    All reservation inserts use ACID database transactions with rollback on failure.
