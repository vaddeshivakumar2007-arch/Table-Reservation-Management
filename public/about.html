System Architecture

Technical Specifications & Database Schema

Table: customers

Stores user accounts with encrypted passwords (bcrypt), uniquely indexed emails, and session identifiers.

  • customer_id (PK, AUTO_INCREMENT)
  • name (VARCHAR 100)
  • email (VARCHAR 100, UNIQUE)
  • phone (VARCHAR 15)
  • password (VARCHAR 255, Bcrypt)

Table: tables

Maintains the physical seating layout, guest limits, scenic locations, and availability statuses.

  • table_id (PK, AUTO_INCREMENT)
  • table_number (VARCHAR 20, UNIQUE)
  • seating_capacity (INT)
  • location (VARCHAR 50)
  • status (VARCHAR 20, 'Available')

Table: reservations

Connects customers with tables, enforces time slots, and tracks approval workflows.

  • reservation_id (PK, AUTO_INCREMENT)
  • customer_id (FK → customers)
  • table_id (FK → tables)
  • reservation_date (DATE)
  • reservation_time (TIME)
  • guests (INT)
  • status (Pending/Confirmed/etc.)
